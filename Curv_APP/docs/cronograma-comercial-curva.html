3. Tabla detallada por frente
Frente Semanas Objetivo Entregable Owner sugerido Criterio de cierre Riesgo principal
2.1 Backend legible + metadata
Dependencia: inicio		 S1-S2 Normalizar estructura y trazabilidad para escalar funciones. Schema legible + endpoints base + metadata explotable. Tech Lead Documentacion minima + pruebas de lectura/consulta estables. Deuda tecnica previa ralentiza limpieza.
2.2 Usuarios / inicio de sesion
Depende: 2.1		 S3-S4 Habilitar multiusuario y control de acceso. Login funcional, sesiones activas y permisos base. Full-stack Registro/login/logout y recuperacion de acceso operativos. Seguridad incompleta en primeros pases.
2.3 Monedas S/ USD EUR
Depende: 2.2 (parcial)		 S4-S5 Soporte comercial multipais en propuestas. Select de moneda + conversion + formato consistente. Producto + Frontend Calculos y documentos muestran moneda correcta sin errores. Inconsistencias de redondeo por herramienta.
2.4 Landing page de ventas
Depende: 2.2 y 2.3		 S5-S6 Capturar demanda calificada con mensaje claro. Landing publicada con CTA, prueba social y formulario. Marketing + Diseno Tracking de leads, eventos y canales funcionando. Mensaje comercial poco especifico.
2.5 Hosting
Depende: 2.1 y 2.4		 S6 Publicacion estable para uso real. Entorno productivo, dominio, SSL, backup y monitoreo. DevOps / Tech Lead Deploy reproducible + uptime objetivo inicial. Configuracion incompleta en salida.
2.6 Marketing / ventas / pipeline
Depende: 2.4 y 2.5		 S7-S9 Generar flujo continuo de oportunidades. Embudo con fuentes activas, CRM y cadencia comercial. Growth + Ventas Pipeline semanal con etapas y responsables definidos. CAC alto por falta de foco de canal.
2.7 Mercado / pricing / entrada
Depende: 2.6		 S10-S12 Optimizar oferta para escalamiento comercial. Paquetes de pricing, segmento objetivo y narrativa final GTM. Founder + Comercial Playbook de ventas y politica de precios aprobada. Subprecio o sobreprecio sin validacion suficiente.

Hito Semana Decision de management
Gate tecnico: backend + auth aceptados 4 Autorizar implementacion de monedas y preparacion comercial.
Go-live: landing + hosting operativos 6 Iniciar inversion comercial planificada y pipeline semanal.
Gate comercial: primer ciclo de ventas medido 9 Ajustar CAC, mensaje y canales con datos reales.
Gate estrategico: pricing + entrada a mercado 12 Definir plan de escalamiento del trimestre siguiente.

Recomendacion operativa: comite semanal de 45 minutos (tech + comercial) para controlar desviaciones.
